# 无障碍权限申报口径（国内应用商店）

**状态：** 已定稿（2026-10-13，第二十一轮 REQ-83 / T21-1）
**适用范围：** 华为应用市场、小米应用商店、OPPO 软件商店、vivo 应用商店、腾讯应用宝等国内主流商店的**上架 / 更新申报**
**配套物料：** `docs/legal/accessibility-disclosure.md`（用户可见说明）；`docs/legal/accessibility-play-declaration.md`（Google Play）；`docs/adr/ADR-016-autobook-capture-architecture.md`

> **为什么单列一份：** 国内商店对上架应用申请「无障碍」这类高敏权限普遍要求**单独申报用途**并可能人工审核。这是**上架前置物料**——**不得先写码后补合规**（决策 #2 / #18）。本文给出可直接复用的口径与话术；**各家后台字段与措辞会变，提交前须按当次后台的最新要求逐条核对**。

## 一、申报时的事实基础

申报内容必须与**代码事实**一致，逐条可核对：

| 申报点 | 代码事实 | 可核对的证据 |
|---|---|---|
| 申请的无障碍能力 | 仅 `TYPE_WINDOW_STATE_CHANGED` / `TYPE_WINDOW_CONTENT_CHANGED` **事件订阅** | `res/xml/accessibility_service_config.xml` 的 `accessibilityEventTypes` |
| **不**申请手势能力 | 配置中**无** `canPerformGestures` | 同上；`SecurityConfigTest.kt` 反向断言 |
| **不**执行任何操作 | 服务代码**无** `performAction` 调用 | 服务源码 + 用例守护 |
| 作用范围受限 | `packageNames` **只列用户选定的来源包** | 配置 XML（运行期随用户选择更新） |
| **不**新增普通权限 | `<uses-permission>` 集合逐条不变 | `AndroidManifest.xml` + `SecurityConfigTest.kt` |
| 是否系统无障碍工具 | **不是**（`isAccessibilityTool="false"`） | 配置 XML |
| 数据处理位置 | 预筛在设备内，非支付内容当场丢弃；仅疑似交易文本上行解析 | 隐私政策 §2.4；过滤器用例 |

## 二、用途说明（可直接用于申报的字段）

**服务名称：** Aozora 自动记账

**用途描述（简洁版，约 100 字）：**

> Aozora 使用无障碍服务实现「自动记账」：当用户在微信、支付宝等**支付类应用的支付结果页 / 账单页**时，读取该页**可见文字**，识别出金额与商户，生成一笔**记账草稿**，免去用户手动记录。服务**只读取文本、不执行任何点击或操作**，也不会读取与支付无关的页面。

**用途描述（详细版）：**

> 1. **读取范围**：仅在用户**自行选定**的支付类应用处于**支付相关页面**时，读取该页面可见文本（金额、商户名、时间、订单号等）。
> 2. **不读取**：与支付无关的页面不读取（其他页面连文本都不采集）；不读短信、通讯录、位置、聊天内容。
> 3. **不操作**：无障碍服务**只读不写**，不执行点击、输入、手势；不申请悬浮窗权限；不注入第三方进程。
> 4. **用户控制**：该能力**默认关闭**，须用户**显式授权**并自行开启；可随时在系统无障碍设置或应用内关闭，**关闭即停止采集**。
> 5. **数据处理**：是否为支付类内容的判定在**设备内**完成，非支付内容当场丢弃、不存储、不上传；命中的原始文本先存本机数据库，仅疑似交易文本上行服务端解析。

## 三、在架先例（可引用）

同类自动记账产品在国内商店**均有在架先例**，申报口径可参考，用于证明「该权限在本类产品中有正当用途」：

- **钱迹**（无障碍自动记账，主通道）
- **iCost 记账**（无障碍自动记账）
- **小星记账**（无障碍 + 通知）

申报时若审核方对用途有疑问，应对齐上述产品的**「读屏记账」定位**，并强调本产品**只读不写、不操作第三方应用**这一与「智能体代操作」的分界线。

## 四、提交前逐条核对清单

- [ ] 用途描述与触达的用户可见文案（`accessibility-disclosure.md`）**一致**，无夸大
- [ ] 应用内**存在**无障碍用途说明页与**撤销入口**（软协标准要求「明确授权 + 便捷撤销」）
- [ ] 隐私政策 §2.4 已披露读取范围 / 处理位置 / 上行范围 / 撤销方式
- [ ] 商店后台「敏感权限」或「无障碍」专项声明已填写（各家字段名不同，按当次后台）
- [ ] 若审核要求提供演示视频或功能说明，以「打开支付页 → 自动生成草稿 → 在待确认箱确认」为演示路径
- [ ] 本次申报的措辞**不得**出现「100% 自动」「绝不遗漏」类表述（决策 #20）
