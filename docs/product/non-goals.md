 # 非目标（Non-Goals）
 
 **状态：** 已定稿 | **v1 全程不做**
 
 | 项目 | 理由 |
 |---|---|
 | 多币种 | 偏离单人极简记账主轴 |
 | ~~云同步 / 跨设备~~ | **已作废（2026-10-13）**：账号、云端保存与跨设备恢复已进入生产范围（`docs/APP-CONTEXT.md` §2.4 已声明其不再属于非目标），本行不再成立 |
 | 情侣/家庭共享账本 | 偏离单人场景，商业化验证后再评估 |

 | iOS 版 | 同一 Web 前端可用 Capacitor 评估，但非本期目标 |
 | 网页版 | 移动端为主 |
 | 广告变现 | 只卖会员不卖广告 |
 | 读取短信 / 悬浮窗 / 第三方接口对接 / 自动操作第三方 App | **不做**。自动记账的采集**仅经无障碍服务（只读）与通知监听两条通道**：银行短信走通知监听覆盖（不申请 `READ_SMS`）、确认触达用通知替代悬浮窗（不申请 `SYSTEM_ALERT_WINDOW`）、不注入第三方进程。详见 `docs/adr/ADR-016-autobook-capture-architecture.md` |
