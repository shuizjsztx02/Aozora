 # 产品原则
 
 **来源：** PRD §3 | **状态：** 已定稿
 
 所有设计争议的裁决准绳，以下原则优先级从高到低。
 
 | # | 原则 | 含义 |
 |---|---|---|
 | **PR-1** | AI-native，无表单 | 一切操作（记账/查询/改设置/建分类）都能用一句话完成；手动表单只是兜底，不是主路径 |
 | **PR-2** | 准确高于省事，但别打断 | 高置信快速通道自动入账但必须立即可见、带撤销按钮可随时撤销；低置信一律出确认卡。**永不产生用户不知情的账目** |
 | **PR-3** | 本地优先 | 断网时全功能可用（规则引擎 + 离线语音）；数据默认只在设备上，云端能力是增强不是依赖 |
 | **PR-4** | 共情不说教 | 超支时安慰，省钱时庆祝；禁止评判性措辞。这是与小贝人设绑定的品牌资产 |
 | **PR-5** | 10 秒上限 | 从掏手机到这笔账记完（含确认），中位数 ≤10 秒 |
 | **PR-6** | 高颜值是功能 | Aozora 四时天空画布是差异化的一部分，不是装饰 |
 
 ## 决策记录
 - **PR-1 至 PR-6：** 用户确认
 - **PR-2（D3 入账确认策略）：** 快速通道自动入账 + 带撤销按钮，可随时撤销（2026-08-27 拍板）
