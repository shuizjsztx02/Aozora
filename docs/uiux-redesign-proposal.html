Aozora — 秩序不变，画布换成天空

V5 的全部秩序感原样保留：TikTok 七规则的交互骨架、四套组件语法、底部弹层、中央 ＋、单一强调色的纪律。改变的只有一件事——画布不再是纯色，而是一整幅新海诚式的天空场景：有体积的积雨云、斜进画面的柔光带、落日的光晕、飞鸟、电线杆剪影；夜里有月牙、银河淡带与一道彗尾。随手截一张图，就是一张美景；打开 app 记一笔，像在明信片上写了一行字。

Why Sky

为什么天空适合一部记账 app

新海诚的画面之所以击中人心，不是因为它"好看"，而是因为它把时间画了出来——光的角度、云的厚度、天的颜色，全都在说"此刻只有一次"。记账恰好也是一门关于时间的功课：今天的钱花在哪、这个月还剩多少。两者在"今天"这个词上相遇：

新海诚画面语言在 Aozora 中的翻译
天空即主角
《天气之子》里天气是角色不是背景		每片天空是一个分层 SVG 场景（渐变天幕 → 光源 → 柔光带 → 有体积的云 → 地平线剪影 → 飞鸟），占满画布，内容浮在其上
魔法时刻
黄昏几分钟内颜色流变		四时主题跟随真实时间自动切换：清晨 5–10、白天 10–17、黄昏 17–19、夜晚 19–5。晚上打开 app，手机里的天和你窗外的是同一片
光是一等公民
光束、逆光、镜头光晕		拂晓/白日有从画外斜进来的柔光带（渐变多边形+厚 blur，不再是硬边色块）；黄昏有落日光晕把云底染成金橙；英雄数字带极轻辉光
云的体积感
夏日积雨云压在地平线		每朵云由 4–7 个椭圆叠出体积，白色受光面 + 灰蓝/紫灰的底面阴影，轻微 blur 融入天色——不是白色贴纸，是有重量的云
风景的边角
电线杆、树影、飞鸟		黄昏与夜晚的地平线有树影/屋顶与电线杆的剪影，电线上还挂着两道弧；白天有远处的小云和一对飞鸟——"有人在生活"的证据
彗星/流星
《你的名字》的划痕记忆点		夜间右上角彗尾（渐变细线+光点头部）与月牙、银河淡带同框——克制到几乎要发现才看得到
电影字幕卡
明朝体+大字距的标题字		日期行用衬线体 + 0.2em 字距（思源宋体）："八月二十六日 · 星期二"。唯一的字体破例，P1 打包子集仅约 20KB

情绪价值对目标用户的含义：记账常被做成"管理工具"，冷而正确；天空把它变成"记录今天"——每天的天空都不一样，就像每天的生活。这正好接住产品哲学"别家 app 让你对钱焦虑"：看着傍晚的天空记完账，合上是安心，不是愧疚。

Four Skies

四时令牌系统

仍是 V5 的令牌架构，从双模式扩为四时刻。天空场景是唯一的表现层；文字、弹层、导航的材质全部由令牌驱动，保证任何天空下可读。强调色随时辰变化——进度条的颜色就是此刻天空的颜色。

切换逻辑：默认跟随系统时间（分钟级检查）；设置页可固定任一时辰。磨砂玻璃导航与弹层用半透明底色吃到当前天空的颜色，同一套组件在四个时辰下都"长在这片天上"。语义色不动：收入绿 / 预警琥珀 / 超支红，支出永不标红。

可读性纪律（美景的前提是看得清）

约束数值
正文/天空最低对比度≥ 4.5:1 —— 文字活动区（上 40% 天幕）的色阶全部按此校准（如白日顶部 #3F8CD3 上 #122031 ≈ 5.9:1，黄昏顶部 #8496CC 上 #241C36 ≈ 6:1）
云与剪影的位置主体云群只出现在画面下 1/3 与边缘；黄昏高处逆光云 opacity ≤ 0.5 且加厚 blur；剪影只住在导航玻璃之后
颗粒层全局 opacity ≤ 0.06，静态
图表工作色沿用已过色觉校验的五色组并直标，不随天空变化——数据的一致性高于氛围
性能红线天空=静态分层 SVG，一次合成；blur 只在导航/弹层两处；无循环动画默认值。低端机「氛围层」开关可退回纯色渐变（令牌架构保证色彩关系不变）

Other Screens

其余页面如何穿上天空

结构与 V5 完全一致，只有画布与玻璃材质随主题：

页面套用方式
明细同一片天空做画布；日分组小节头、发丝线流水不变；月份切换器变磨砂胶囊。往下滑动时天空视差滚动（0.5 倍速）——云在慢慢后退，流水在指尖前进
报表总额数字坐在天上；条形直标排行的轨道用半透明白，工作色五色不变；下钻弹层=磨砂玻璃
我的「外观」里放四时预览缩略图（四枚小天空圆片）＋"跟随时间/固定"开关＋"氛围层"低耗开关
超支警示琥珀警示条仍为行内横幅（非弹窗）。警示只用颜色和文案，不用天气做文章——克制
Motion

动效：天空可以动，但默认很慢很轻

场景规格目的
时辰切换瞬间两层场景交叉溶解 800ms ease（每天最多 3 次）"天黑了"被感知而不被打扰
云漂移默认关闭；开启后整组云 90s 循环平移 6px生命感，零功耗焦虑
彗尾仅在打开首页的前 2 秒淡入一次，之后静止发现感属于第一次
Sheet / 数字 count-up / 列表 stagger沿用 V5 规格（320ms 弹簧 / 500ms / 24ms）秩序感不动摇

一切遵循 prefers-reduced-motion 与「氛围层」开关：关闭后四时只剩单层渐变，云/星/彗尾/剪影全部移除。

Self Audit

十条清单复查（在 V5 通过的基础上增量）

检查项天空版的回答
② Hierarchy 第一焦点天空再美也是低对比背景；54–58px 数字永远是最响的元素。眯眼看每一帧：先见数字，再见天色
④ Information Density装饰全部住在背景层，前景信息量与 V5 逐字节相同：1 数字、1 进度、4 行流水
⑨ Visual Noise新增的表达只有一个通道（天空场景），且自带四条硬约束（对比度/位置/透明度/可关闭）。每个时辰仍然只有一个彩色
⑩ States 完整性新增状态：低电量/省电模式→自动关氛围层；低端机降级→单层渐变；时辰边界→交叉溶解已覆盖

其余六项（Goal / Primary Action / Depth / Context / Thumb Zone / Consistency）与 V5 完全一致，无回归风险。
