## 第二十二轮设计决策（所有任务卡必须遵循，勿重新发明）

1. **M8 归属**：用户 2026-11-10 指定归入里程碑 M8，任务卡用 `T-M8-01…09`，**不再套 T22-x 轮次编号**（与轮次编号规则的有意偏离，理由＝用户指令优先）。
2. **不做 OTel / Prometheus / Grafana**：后端数据面是 PostgreSQL 的事件日志与业务表；曲线和告警维持现状（生产关闭）。
3. **会话检索是会话级**：用户要的是「找到某次会话」，不是「事件级全文检索」；`search_text` 建在 `ai_conversations` 上，`tool` 结果不进检索面。
4. **审批四值的两个来源必须分开呈现**：服务端可观测的 `allowed-once` 与客户端上报的其余三值；**老客户端未上报时显示「未上报」，不得推断为拒绝**。
5. **管理端身份独立**：`admin_accounts` + 独立 secret/audience；**不给 `users` 加 `is_admin`**。
6. **读为主、写受限**：读端点一律只读事务；写能力仅限三项账户操作（暂停/恢复、guest 日配额覆盖、强制登出），**禁止改业务数据行**。后台暂停**不得复用 `UserStatus.FROZEN`**（删除任务会物理删除该状态用户），用 `admin_suspended_at`。
7. **迁移串行**：8-03 先占 revision，8-02 的新表迁移不得分叉。
8. **`search_text` 与事件同寿**：保留期清理必须同步重算检索文本（与 T-M7-04d「摘要随正文清掉」同源）。
9. **`§4.6` 口径裁决**：应用日志仍禁止完整对话；会话正文仅存事件日志，受保留期与访问审计约束。
10. **决策已锁定**：2026-11-10 用户逐项确认 24 项（17 项主决策 + 7 项补充确认），清单见 `docs/architecture/admin-console.md` §9；实施中不再重议。要点包括：M8 在 M6 之前、多管理员、公网子域、三项写操作、四值上报、只搜 user/assistant、全局搜索、事件表加 `request_id`、保留期空态、只记登录、打码 + 查看明文审计、导出三范围两内容、隐私政策更新、北京时间、自建 Vite + TanStack。

**④ 分步 token 用量观测（2026-11-12 追加 · REQ-85 → T-M8-12）**

> 用户原话（2026-11-12）：希望 token 消耗观测从「一轮次总 token」进一步细化到**每一个环节的输入输出 token——调用一次工具、一次模型推理思考这样的每一小步**。

**现状（已核实）**

- 每步用量**拿得到但被丢掉**：`AgentObserver.step_finished(step, prompt_tokens, completion_tokens)`（`server/src/modules/ai/agent.py:1019-1026`）已在 loop 内逐 Step 回调，但只被累加进轮合计（`agent.py:1349-1350`），落库只有每轮一条 `quota`（`conversation.py:1197-1248`）。
- 撞硬边界的收尾模型调用（`agent.py:1957-2007`）用量只进合计、无法归属到任何一步。
- 摘要压缩那次模型调用的用量被**完全丢弃**（`conversation.py:650-673` 只取 `content`）——既不在事件里，也不在 `ai_usage` 里。
- 回放台因此只能显示「第 N 轮：model / prompt X / completion Y」（screenshot #6 的 #34 行）；工具调用卡 #31 上看不到它这一步推理花了多少。
- 约束：guest 日配额按 `ai_usage` **行数**计数（`service.py:227-252`），所以分步用量**不能**新增 `ai_usage` 行。

**方案（最小改动，明确不做什么）**

- 新结构性事件 `usage`，**每次模型调用一条**：`{kind: step|wrap_up|summary, step, level, provider, model, prompt_tokens, completion_tokens, tokens, tool_calls:[{id,name}]}`。
- Step 事件在模型调用返回后、该步 assistant 落库批之前写（`seq` 紧邻）；`summary` 在压缩调用成功后写（摘要被拒也写）。随批提交，断连也留档。
- `quota` 与 `ai_usage` 口径一字不动；不变量 `quota.tokens == Σstep + Σwrap_up`。
- 管理端：时间轴新增 `usage` 行（Step / 档位 / 输入 / 输出 / 工具），并按 `tool_call_id` 在工具卡上标注「本步用量」。
- **不做**：不新增 `ai_usage` 行；不改配额；不做输入/输出差价、cache 命中、reasoning token 拆分；不覆盖快路径；不加桥命令、客户端零改动；无迁移。
